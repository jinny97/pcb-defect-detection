# pcb-defect-detection
AI-based PCB defect detection for automated visual inspection

## Overview

This project explores an AI-based computer vision pipeline
for detecting and classifying PCB defects.

## Motivation

Automated optical inspection is widely used in PCB manufacturing.
This project investigates how deep learning can be applied
to visual defect inspection.

## Objectives

- Build a PCB image classification pipeline
- Train a baseline deep learning model
- Evaluate model performance
- Analyze false positives and false negatives
- Discuss potential industrial application

## Tech Stack

- Python
- PyTorch
- OpenCV
- NumPy
- Pandas
- scikit-learn
- Matplotlib
